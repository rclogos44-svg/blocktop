Drop Mixamo clips here as `<ClipName>.fbx` (for example `Dribble.fbx`, `Crossover.fbx`, `Jumper.fbx`, `Dunk.fbx`), then rerun `python blender/build_player.py`. Each one replaces the hand-keyed clip of the same name in `assets/player.glb`, or is added as a new clip.

Mixamo download settings: **FBX Binary**, **Without Skin**, **30 fps**, and tick **In Place** when it's offered.
